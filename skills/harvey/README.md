# Harvey Sales Skills Library

The nine framework files in this directory are imported from [`ethanplusai/harvey`](https://github.com/ethanplusai/harvey), preserved under the MIT License. See `LICENSE` for the required attribution.

`product_knowledge.md` and `competitive_intel.md` are Scout workspace files. They are intentionally editable local overlays for the website development, SEO, redesign and management software services offered by this workspace; they are not represented as original Harvey content.

Skills are copied into the local SQLite Skills Library on first startup. Later edits are stored locally and are not overwritten by reseeding.
